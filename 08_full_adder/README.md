# Full Adder

## Objective

Design and simulate a 1-bit Full Adder using Verilog HDL.

## Tools Used

- Icarus Verilog
- GTKWave
- VS Code
- Ubuntu (WSL)

## Files

- `full_adder.v` – RTL module
- `full_adder_tb.v` – Testbench
